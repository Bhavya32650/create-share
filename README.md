# SkillMatch AI – Content-Based AI Recommender

## DecodeLabs Industrial Training Kit – Project 3

SkillMatch AI is an intelligent recommendation system that matches user skills with suitable technology careers using Content-Based Filtering techniques.

The application transforms selected skills into TF-IDF vectors and ranks job roles using Cosine Similarity, providing personalized career recommendations.

---

## Overview

This project demonstrates how recommendation systems work using Natural Language Processing concepts and similarity-based ranking.

Users select skills from a predefined skill database, and the system recommends the most relevant technology roles.

---

## Features

* Interactive Skill Selection
* Content-Based Recommendation Engine
* TF-IDF Vectorization
* Cosine Similarity Ranking
* Career Matching System
* Real-Time Recommendations
* Top-N Role Ranking
* Responsive User Interface
* Fast Client-Side Processing

---

## Recommendation Workflow

### Input

User selects skills such as:

```text id="tn68gq"
Automation
CSS
Data Visualization
Deep Learning
```

### Processing

1. Convert skills into TF-IDF vectors.
2. Convert job profiles into TF-IDF vectors.
3. Calculate Cosine Similarity scores.
4. Rank jobs based on similarity.
5. Display Top Matching Roles.

### Output

The system recommends roles such as:

* Data Scientist
* Frontend Developer
* Full Stack Developer

with similarity scores.
